How the Scrapbook Works — play with it

The designer crafts an empty picture-frame page; the fan slips photos into its windows. All inside the site's own studio.

i — the designer

Uploads artwork, draws windows

One background image + optional transparent-PNG ornaments. Then in the canvas studio they DRAW where photos go — the windows are saved coordinates, not files.

uploads: JPG / PNG images only
ii — the template

Becomes a recipe, not a file

Saved as image URLs + a layout JSON. Admin approves; it appears in the fans' list with a preview.

stored: images + layout JSON
iii — the fan

Fills windows, writes, exports

Tap a window → pick a photo → it snaps in auto-cropped, draggable to reframe. Write the memory. Export presses it all into a printable PDF.

exports: PDF (output only)
